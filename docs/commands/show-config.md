```
用法: freqtrade show-config [-h] [--userdir PATH] [-c PATH]
                             [--show-sensitive]

选项:
  -h, --help            显示此帮助消息并退出
  --userdir PATH, --user-data-dir PATH
                        用户数据目录路径。
  -c PATH, --config PATH
                        指定配置文件（默认：
                        `userdir/config.json` 或 `config.json`，以存在者为准）。
                        可以使用多个 --config 选项。可以
                        设置为 `-` 以从 stdin 读取配置。
  --show-sensitive      在输出中显示密钥。

```
