# FreqUI 界面汉化指南

## 概述

FreqUI 是 Freqtrade 的 Web 前端界面，用于监控机器人并与机器人交互。界面汉化包括两个部分：

1. **FreqUI 前端界面**（独立仓库，需要单独处理）
2. **后端 API 响应消息**（当前仓库，API 返回的文本）

## FreqUI 前端界面

### ⚠️ 重要说明

FreqUI 是**独立的 GitHub 仓库**，前端代码不在当前的 `freqtrade` 仓库中：

- **仓库地址**：https://github.com/freqtrade/frequi
- **技术栈**：TypeScript/React 等现代前端框架
- **语言文件**：通常位于 `src/locales/` 或类似的国际化目录

### 如何开始前端界面翻译

#### 1. 克隆 FreqUI 仓库

```bash
# 克隆 FreqUI 仓库
git clone https://github.com/freqtrade/frequi.git
cd frequi
```

#### 2. 查找语言文件

FreqUI 可能使用以下国际化方案之一：

- **i18next**：查找 `locales/` 或 `src/locales/` 目录
- **react-intl**：查找 `src/i18n/` 或 `messages/` 目录
- **自定义方案**：查找包含 `en.json`、`zh.json` 等语言文件的目录

常见文件结构：
```
frequi/
├── src/
│   ├── locales/
│   │   ├── en.json          # 英文翻译
│   │   ├── zh.json          # 中文翻译（需要创建）
│   │   └── ...
```

#### 3. 创建中文翻译文件

1. 复制英文语言文件作为模板：
   ```bash
   cp src/locales/en.json src/locales/zh.json
   ```

2. 翻译所有键值对：
   ```json
   {
     "common": {
       "save": "保存",
       "cancel": "取消",
       "loading": "加载中..."
     },
     "trades": {
       "title": "交易",
       "open_trades": "未平仓交易"
     }
   }
   ```

3. 注册中文语言支持（通常在 `src/i18n/config.ts` 或类似文件中）：
   ```typescript
   import zh from './locales/zh.json';
   
   const resources = {
     en: { translation: en },
     zh: { translation: zh }
   };
   ```

#### 4. 构建和测试

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

### 界面翻译内容

需要翻译的主要界面元素：

- ✅ **导航菜单**：主页、交易、回测、设置等
- ✅ **交易视图**：交易列表、开仓/平仓按钮、盈亏显示

- ✅ **错误提示**：表单验证、操作反馈消息
- ✅ **状态消息**：机器人状态、交易通知

## 后端 API 响应消息

后端 API 返回的消息也会在界面中显示。这些消息位于当前 `freqtrade` 仓库中，可以直接翻译。

### 需要翻译的文件

1. **API 响应消息**：
   - `freqtrade/rpc/api_server/api_v1.py` - API 端点响应
   - `freqtrade/rpc/api_server/api_*.py` - 其他 API 模块

2. **RPC 消息**：
   - `freqtrade/rpc/telegram.py` - Telegram 消息格式化（部分可能在 UI 中显示）
   - `freqtrade/rpc/rpc.py` - RPC 异常消息

3. **错误消息**：
   - `freqtrade/exceptions.py` - 异常消息
   - `freqtrade/rpc/rpc.py` - RPCException 消息

### 翻译方法

后端消息通常以字符串字面量的形式出现，例如：

```python
raise RPCException('*Status:* `no active trade`')
```

翻译为：

```python
raise RPCException('*状态：* `没有活跃交易`')
```

**注意**：翻译时要保持 Markdown 格式和特殊字符。
